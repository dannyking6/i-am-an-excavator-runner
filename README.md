# Quarry Quest

## About the game
Quarry Quest puts you behind the controls of a trusty excavator and a job list that never gets shorter. Every contract drops you into a dusty pit where the bucket has to bite into rock, load up, and get the haul out before the light goes. The machine is heavy, the ground is uneven, and every scoop of fuel you burn is a scoop you have to earn back before the day is done.

Between jobs the take goes straight into the garage: patch the damage, top up the fuel, squeeze a little more speed out of the hydraulic pump, and then head back down into the dirt. There is a practise mode to learn the levers, a ladder of jobs that gets messier as you climb it, and a deeply satisfying moment when the bucket finally bites deep and the whole machine leans into the pull.

## Controls
### Smartphone & tablet
Use the on-screen arrow pad to pull the gear lever and work the other levers, tap the key button to press the key, and hold the accelerator button to push the digger forward. Tap the buttons on the dashboard to start a job.

### Desktop
Pull the gear lever with the A, S and D keys, work the other levers with the number keys 1 to 9, press Enter to hit the key, and hold Space to push the accelerator.
> Trackpad: single click = same as left-click.
